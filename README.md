# 👕 Fashion-MNIST Image Classification with PyTorch

Проект по глубокому обучению (Deep Learning), реализующий сверточную нейронную сеть (CNN) для классификации изображений одежды.

---

## 🧠 1. Описание архитектуры и данных
* **Датасет:** `Fashion-MNIST` (60,000 обучающих и 10,000 тестовых черно-белых изображений одежды размером 28x28 пикселей, разделенных на 10 классов: футболки, брюки, платья, кроссовки и т.д.).
* **Стек:** `Python`, `PyTorch`, `Torchvision`, `Matplotlib`.
* **Архитектура сети:** Сверточная нейросеть (CNN), состоящая из:
  * Двух блоков сверточных слоев (`Conv2d` + `ReLU` + `MaxPool2d`) для извлечения признаков.
  * Полносвязных слоев (`Linear`) для финальной классификации.

---

## 📈 2. Результаты обучения
Модель обучалась с использованием оптимизатора **Adam** и функции потерь **Cross-Entropy Loss**:
* Достигнутая точность (**Accuracy**) на независимой тестовой выборке составила **~89%**.
